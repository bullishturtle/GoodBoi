# GoodBoy.AI - Simplified Self-Learning Assistant

GoodBoy.AI is a modular AI assistant designed to learn and enhance itself. The system is built around a core architecture with specialized agents for different tasks.

## Core Features
- **Self-Learning**: Continuously improves its capabilities.
- **Modular Design**: Easily extendable with new agents.
- **Automation**: Handles repetitive tasks efficiently.

## Quick Start
1. Install Python 3.10+.
2. Run `INSTALL.bat` to set up the system.
3. Use `GoodBoy_launcher.bat` to start the server and UI.

## Architecture
- **Core Agents**:
  - **Jarvis**: System control and coordination.
  - **DaVinci**: Creativity and design.
  - **Analyst**: Data analysis and insights.
- **Districts**:
  - **Infrastructure**: Core system resources.
  - **Data Towers**: Information storage and analysis.
